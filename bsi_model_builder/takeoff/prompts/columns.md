Take off every steel column on this sheet (column schedule and/or foundation plan). You are given the page
image, the page text, the grid calibration (grid tags → feet; the datum is the first numbered grid / first
lettered grid at the slab elevation unless the plan states otherwise) and the centres of the column symbols
in grid feet. For each column: mark, size as printed, grid intersection, x/y in grid feet, top of footing and
top of steel elevations relative to the datum (read the footing tags / schedule; state the convention in
`datum`), height = T/STL − T/FTG, base plate, anchor rods, rotation (0 = flanges parallel to the numbered-grid
direction), finish, grade. Then list base plates by mark with quantities, plate washers if shown, and anchor
rod groups (per item × item qty, length as printed, finish, grade). If a height depends on something not on
the sheet (a T/STL on another sheet, an unlabelled footing), carry the best-supported value, mark the row with
an RFI draft, and say in `notes` which value you carried.
